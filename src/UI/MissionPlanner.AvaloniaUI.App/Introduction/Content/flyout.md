The **Flyout Menu** on the left is MissionPlanner's primary navigation. It groups the application by task rather than trying to place every function on one screen.

## Using the Flyout

- Open or expand the Flyout to see the available sections.
- Select a page to replace the main content area.
- Collapse the Flyout when you want more horizontal space for maps, telemetry, or parameter tables.
- Changing page does **not** disconnect the vehicle. Connection state is application-wide and remains visible in the Top Bar.

On smaller screens the Flyout becomes especially important because it keeps application navigation separate from the current working page.

## Think in tasks

The major areas normally correspond to tasks such as:

- flight monitoring;
- mission planning;
- vehicle setup and configuration;
- firmware and maintenance;
- application preferences.

The exact entries can evolve as MissionPlanner gains more capabilities. The important rule is that the Flyout chooses **where you work**, while controls inside the selected page perform the work.
