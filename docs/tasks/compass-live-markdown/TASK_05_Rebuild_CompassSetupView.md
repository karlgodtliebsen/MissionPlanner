# TASK 05 — Rebuild CompassSetupView Around the New UX

## Goal

Turn `CompassSetupView` into the first full subsystem-oriented Setup page.

Use native Avalonia controls for interaction and `InformationDocumentView` for longer selectable information.

## Recommended layout

```text
Compass
────────────────────────────────────────────

Status
  [InformationDocumentView]

Configuration
  [ ] Enable Compass

  Use primary Compass
  [ toggle ]

  Yaw source
  [ friendly ComboBox ]

  Orientation
  [ friendly ComboBox ]

Calibration
  status / progress
  [ Start Calibration ]
  [ Cancel ] where supported

Advanced
  compact relevant parameter/details area
  [ Open Full Parameters ]

Pending changes footer
  [ Discard ]                    [ Apply ]
```

Use existing `SectionCard` styling.

## Friendly controls

The user must not need numeric enum values.

Examples:

```text
Yaw source: None / Compass / other supported values
Orientation: None / Yaw 45 / Yaw 90 / ...
```

Use parameter metadata where available.

Parameter names may appear as small secondary text:

```text
COMPASS_ENABLE = 0
```

but must not be the primary label.

## Status document

Bind the Markdown wrapper to the `UserDocument` generated by the Compass document factory.

Do not generate Markdown in XAML code-behind or the ViewModel.

## Calibration

Preserve existing Compass calibration functionality.

If Compass is disabled, disable calibration and explain why.

## Advanced

Show the relevant expert information only.

Do not reproduce the complete Full Parameters page.

Normal Compass configuration must not require leaving this page.

## Loading/disconnect

Do not briefly display false values from uninitialized properties.

Explicitly represent:

```text
Loading…
Disconnected
Unsupported
```

## Responsive layout

Verify:

- normal desktop width;
- narrow window;
- high DPI;
- Browser/WASM;
- long Markdown;
- dark/light theme.

Avoid fixed document heights that clip content.

## Acceptance criteria

A user can understand, configure, calibrate and inspect Compass without opening Full Parameters, while an expert can still see the underlying parameter names/values.
