# Features

## Modern ArduPilot firmware workflow

Mission Planner includes a data-driven firmware page with connected/disconnected safety modes, cached Stable/Beta/Latest catalogues, all-board choices, local APJ/PX4 packages, serial bootloader discovery across port changes, mandatory compatibility and checksum verification, embedded bootloader update through acknowledged MAVLink commands, returning-device detection, and copyable diagnostics.

See [Firmware architecture and operation](docs/Firmware.md).
