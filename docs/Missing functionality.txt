In FullParametersListTabView there is a Button for "Parameter profiles".
What is it for?
Is it needed when there is a file save/load functionality
how do I create a profile if it is needed


**Parameter profiles is an unfinished feature in the current UI.**

Its purpose is to keep named, reusable parameter sets inside MissionPlanner—for example, “Camera setup” or “Test configuration.” Compared with ordinary parameter files, the underlying profile code supports:

- All parameters, modified parameters, or a selected subset.
- A name, description, and tags.
- Firmware and vehicle information, with mismatch warnings when reused.
- Comparing values and staging compatible differences before applying them.

**You don’t need profiles for normal save/load.** File save/load already supports saving parameter values and importing them as pending edits for review and application.

**Currently, you cannot create a profile through the UI.** Creation and storage exist in the backend, but no creation command is connected to the interface. The current [button handler](/C:/Projects/MissionPlanner/src/UI/MissionPlanner.App/Views/ConfigTuning/Sections/FullParametersListTabViewModel.cs:431) only:

- Shows “No previously saved parameter profiles” when none exist.
- Offers to stage values when exactly one profile exists.
- Lists names when multiple profiles exist—with no selection workflow.

I recommend hiding this menu item until profile creation and selection are implemented. For your current workflow, file save/load is sufficient.
