# MissionPlanner Icon Catalogue

This is the authoritative catalogue of active `Button` elements in application AXAML. MDI is the standard family; prefer outline variants when they preserve the action’s meaning. Ordinary action labels move to tooltips. Data-bearing labels, changing states, and safety-sensitive commands may intentionally retain visible text. Custom recommendations are reserved for vehicle/GCS operations that generic MDI does not clearly express; no custom artwork is introduced here.

Scope: application views, including their in-scope item templates. Excluded: all Dialog/Dialogue views (including dialog hosts whose filenames do not contain “Dialog”), TopBarView, VirtualizedItemsGrid/VirtualizedDataGrid and their controls/templates/sample, commented-out markup, generated/designer files, and test snapshots. Dialog-backed exclusions include ParametersEditorView, ParameterComparisonView, ConnectPopupView, CustomFirmwareView, FirmwareCatalogueView, ConfirmDfuTargetView, DiagnosticsReportView and MissionItemListViewPage. Reusable MissionMapView (used by FlightData and FlightPlanner) and MissionItemListView (also used in the editor drawer) remain in scope.

Line numbers identify the opening Button tag in the final source. “Current Icon” is the actual MDI Kind, or `none` when text remains. “Recommended Icon” is the target design; slash-separated MDI names denote future state-aware alternatives, not a literal Kind. New icons use the shared `ActionIcon` size style. Existing dimensions, commands, layout attributes, and contextual tooltip bindings are preserved.

Vocabulary: local load/save = FolderOpenOutline/ContentSaveOutline; import/export = FileImportOutline/FileExportOutline; read from vehicle/write to vehicle = DownloadOutline/UploadOutline; refresh = Refresh; apply = CheckCircleOutline; apply and persist = ContentSaveCheckOutline; validate = FileCheckOutline; verify = ShieldCheckOutline; revert = FileUndoOutline; reset = Restore; retry = ReloadAlert; cancel = CloseCircleOutline; persistent removal = DeleteOutline; transient clear = Eraser. Domain-specific marker removal uses MapMarkerRemoveOutline.
