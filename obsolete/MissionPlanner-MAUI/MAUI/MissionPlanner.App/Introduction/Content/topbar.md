The **Top Bar** contains controls that are useful regardless of the page currently displayed.

## Vehicle connection

The connection control is the primary entry point for establishing or ending the MAVLink connection. The first release focuses on one active vehicle connection at a time.

A connection can use the transport offered by MissionPlanner, for example a serial/USB connection or a network transport. After connection, MissionPlanner begins receiving vehicle identity, status, and telemetry and makes vehicle-dependent functions available.

> Connecting to a vehicle does not arm it. It establishes the communication link used for telemetry, parameters, missions, and commands.

## MissionPlanner Preferences

The preferences button opens settings that belong to the **MissionPlanner application**, rather than settings stored in the flight controller.

Examples include user-interface behavior, units, map/source preferences, and other workstation-specific options.

The recommended visible name is **MissionPlanner Preferences**. This distinguishes application preferences from vehicle Setup and Configuration.
